# User Guide: ATS Optimized Resume Builder (Excel)

Getting Started
- Open the .xlsm workbook and enable macros.
- The UI sheet provides a section dropdown and an editor area.
- Enter each bullet/line in a separate row. Use "• " prefix for bullets (use "Add Bullet Prefix" to standardize).

Optimize for ATS
- Watch the Keyword Score on the right panel.
- Address Missing Keywords by naturally integrating them into your summary or bullets.
- Avoid tables, images, and unusual formatting.

Versioning
- Use "Save Version" to create checkpoints with a description.
- Compare versions and restore when needed.
- Create branches for different job targets and merge changes.

Export
- Use "Export PDF" to generate a print-ready PDF.
- Use the Export sheet to review the final layout before sending.

Accessibility
- Keyboard navigation is supported (Tab/Shift+Tab).
- Undo/Redo actions available via UI buttons or Excel shortcuts (Ctrl+Z/Ctrl+Y).

Help
- Click "Show Help" or review the HelpDocs sheet for tips, FAQs, and troubleshooting.
